# Xeno Studio - AI Auto Recap & Voice Cloning

## GitHub မှာ တင်ပြီး Vercel ပေါ် Deploy လုပ်နည်း

1. **GitHub Repository အသစ်တစ်ခု ဖန်တီးပါ** (ဥပမာ: `xeno-studio`)။
2. ဤ ZIP ဖိုင်ကို Download ဆွဲပြီး ဖြည်လိုက်ပါ (Extract)။
3. ထွက်လာတဲ့ ဖိုင်တွဲထဲက ဖိုင်အားလုံး (`package.json`, `index.html`, `vite.config.js`, `vercel.json`, `src/`) ကို GitHub Repository ထဲသို့ Upload တင်ပါ (သို့မဟုတ် `git push` လုပ်ပါ)။
4. [Vercel](https://vercel.com) သို့ဝင်၍ **Add New -> Project** ဖြင့် င်း GitHub Repository ကို Import လုပ်ပါ။
5. Build Settings များကို Default အတိုင်းထားပြီး **Deploy** ကို နှိပ်လိုက်ပါ။
